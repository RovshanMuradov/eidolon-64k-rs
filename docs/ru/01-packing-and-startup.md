# 1. Упаковка и запуск

Здесь измерен оригинальный EXE на 60 928 байт. Изменённые кодировщик,
декодировщик и структура PE компактного Rust-порта описаны в разделе
[Compact build and modified assembly](../rust/asm-map.md#compact-build-and-modified-assembly).

EXE — это сжатый kkrunchy поток на 58 844 байта и 2 084 байта обвязки. Распаковщик восстанавливает код, разрешает 35 импортов и передаёт управление на `0x406379`.

## Структура файла

Внешняя обвязка занимает 2 084 байта, из них сам декодер — 1 596.

| Смещение в файле | Байт | Содержимое |
|---|---:|---|
| `[0, 0xd4)` | 212 | Сжатые заголовки DOS, PE, секции |
| `[0xd4, 0xe6b0)` | 58 844 | Общий сжатый поток (range coder) |
| `[0xe6b0, 0xe786)` | 214 | Вспомогательные функции декодера |
| `[0xe786, 0xec94)` | 1 294 | Вход декодера, модель, цикл декодирования |
| `[0xec94, 0xecec)` | 88 | Константы squash и масок контекста |
| `[0xecec, 0xed58)` | 108 | Импорт загрузчика: `KERNEL32!LoadLibraryA`, `GetProcAddress` |
| `[0xed58, 0xee00)` | 168 | Выравнивание нулями |

`SizeOfHeaders = 4096` — это размер отображения в памяти, а не занятые байты: сжатые данные начинаются с `0xd4`.

## Декодер kkrunchy (k7)

Декодер — арифметический кодер с контекстным смешиванием:
- 11 контекстных моделей, предсказание совпадений и повторов;
- смешивание моделей на MMX, адаптивное отображение вероятностей;
- пропуск нулевых блоков по 8 192 байта;
- таблицы состояний генерируются при старте и в файле не хранятся.

## Внутренний загрузчик

Загрузчик занимает 1 501 байт и лежит внутри сжатого потока.

| Адрес | Байт | Роль |
|---|---:|---|
| `0x3f942d` | 64 | Настройка обратного фильтра, проверка окончания |
| `0x3f946d` | 55 | Восстановление стека, загрузка импорта по именам и ординалам |
| `0x3f94a4` | 5 | Переход на `0x406379` |
| `0x3f94a9` | 465 | Обратное преобразование x86-кода |
| `0x3f967a` | 256 | Таблица классов опкодов |
| `0x3f977a` | 576 | Записи импорта приложения |
| `0x3f99ba` | 80 | Длины 20 потоков фильтра |

**Фильтр x86.** Перед сжатием код разложен на 20 потоков (опкоды, ModRM, смещения, адреса переходов и т.д.), чтобы у компрессора были однородные контексты. Обратный фильтр собирает из них 30 279 байт кода в `[0x401000, 0x408647)`.

## Передача управления

```
0x3ee944 декодер → 0x3f942d загрузчик → 0x3f94a4 → 0x406379 приложение
```

Загрузчик записывает `0x3e0000` по адресу `0x400000` (патч совместимости), разрешает импорт через `LoadLibraryA` / `GetProcAddress`, при ошибке возвращается.

## Импорт приложения

35 функций из 5 DLL:

| DLL | IAT | Функции |
|---|---|---|
| KERNEL32 | `0x409010` | GlobalAlloc, GlobalFree, CreateThread, CloseHandle, lstrcmpiA, GetTickCount, GetSystemDirectoryA, CreateFileA, ExitProcess, ReadFile |
| USER32 | `0x409068` | PeekMessageA, CreateWindowExA, GetClientRect, TranslateMessage, DispatchMessageA, GetDC, GetAsyncKeyState, ShowCursor |
| GDI32 | `0x409000` | SetPixelFormat, ChoosePixelFormat, SwapBuffers |
| OPENGL32 | `0x40903c` | glGenTextures, wglMakeCurrent, glGetTexImage, glTexImage2D, glTexParameteri, wglGetProcAddress, wglCreateContext, glBindTexture, glRecti, glViewport |
| WINMM | `0x40908c` | waveOutPrepareHeader, waveOutOpen, waveOutWrite, waveOutGetPosition |

Функции OpenGL новее 1.1 (`glCreateShaderProgramv`, FBO, uniform, 3D-текстуры) загружаются через `wglGetProcAddress`.

## Банк сэмплов `gm.dls`

Интро читает системный банк General MIDI. Путь собирается при инициализации синтезатора:

```
GetSystemDirectoryA(buf, 0x400)                // обычно C:\Windows\system32
strcat(buf, "\drivers\gm.dls")                 // строка в 0x409330
h = CreateFileA(buf, GENERIC_READ, 0, 0, OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, 0)   // 0x40121f
ReadFile(h, 0x4c0c70, 0x9fffff, &n, 0)         // 0x40123e, до ~10 МБ за раз
CloseHandle(h)                                 // 0x401245
```

- Ошибки не проверяются. Если файла нет, синтезатор падает на нулевом указателе сэмпла (`0x404d7b`).
- Банк сканируется по 4-байтовой метке `data`: каждый найденный чанк — один сэмпл, длина берётся из следующего слова (`0x40125f`).
- Эталонный банк — 3 440 660 байт. Реально звучат 15 сэмплов (см. [06-audio.md](06-audio.md)).
