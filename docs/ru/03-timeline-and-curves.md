# 3. Таймлайн и кривые анимации

Таймлайн — 50 строк, покрывающих биты `[0, 600)` без пропусков. Каждая строка выбирает сцену (список проходов) и набор кривых, которые по локальному биту дают значения uniform.

## Таблицы

| Адрес | Формат | Смысл |
|---|---|---|
| `0x42fc50` | 50 × `(f32 start, f32 end)` | Интервалы строк в битах |
| `0x42fde0` | 50 × u32 | Токен сцены |
| `0x42fea8` | 50 × `(wordOffset, count)` | Какие дескрипторы uniform анимирует строка |
| `0x435e2c` | списки с префиксом длины | Список проходов; токен — смещение в DWORD |
| `0x4359d0` | `(programIndex, fboSelector)` | Маршрут прохода; `fboSelector` с единицы, 0 — экран |

Строка выбирается как первая, у которой `end > beat`. При смене строки `localBeat` и треки сбрасываются, даже если токен сцены тот же.

## Сцены

Двенадцать программ сцен распределены по 15 группам строк. Три сцены повторяются в титрах.

| Строки | Биты | Токен | Программа | Содержимое |
|---|---|---:|---:|---|
| 0–4 | [0, 96) | 0 | 9 | жилой модуль, дисплей галактики |
| 5 | [96, 128) | 20 | 19 | модуль снаружи, антенны |
| 6–9 | [128, 176) | 40 | 20 | побережье, монорельс, облака |
| 10–11 | [176, 224) | 60 | 21 | дорога, инопланетная база, облака |
| 12–14 | [224, 264) | 80 | 22 | ангар |
| 15–24 | [264, 336) | 100 | 23 | лабиринт, роботы-преследователи |
| 25–32 | [336, 400) | 140 | 25 | грузовой лабиринт, двери |
| 33–37 | [400, 448) | 160 | 26 | технический туннель, шахта |
| 38–42 | [448, 512) | 180 | 27 | мостки, анимированный босс |
| 43 | [512, 520) | 60 | 21 | снова снаружи |
| 44–45 | [520, 528) | 200 | 28 | сфера, луч |
| 46 | [528, 556) | 220 | 29 | пульт, дисплей галактики |
| 47 | [556, 572) | 40 | 20 | титры: побережье |
| 48 | [572, 584) | 100 | 23 | титры: коридор |
| 49 | [584, 600) | 60 | 21 | титры: снаружи |

- Программа 24 (токен 120, кабельный туннель) скомпилирована, но ни одна строка её не выбирает.
- В шейдерах есть свои события по глобальному времени: программа 25 переключается на 264 и 282 с, программа 26 меняет геометрию на 312 с.
- Список проходов любой сцены устроен одинаково: дескрипторы инициализации 0–8, проход сцены, постобработка 10–18 (см. [05-rendering.md](05-rendering.md)).

## Дескрипторы uniform

Дескриптор — 10 слов u32 по адресу `0x430038 + 4·rowOffset + 40·j`:

```
(nameIndex, components, xOff, xLen, yOff, yLen, zOff, zLen, wOff, wLen)
```

- Имя uniform: `*(0x4361f0 + 4·nameIndex)`, например `uOrigin`, `uAngles`, `uMainCharacterPos`.
- Канал — кривая в пуле по адресу `0x426de0 + 4·off`, длина `len` в словах float32.
- Всего 561 дескриптор и 758 кривых. Компонент от 1 до 3: 295 скаляров, 5 vec2, 261 vec3.
- Загрузка через `glUniform{1,2,3,4}fv` по числу компонент (`0x405fdd`).

Проверка четвёртого канала (`0x407ecc`) читает поле на две записи вперёд. Срабатывает она только на последнем `uAngles` строки 49: лишний W вычисляется, но `glUniform3fv` его отбрасывает.

## Кривая

Кривая — кубический сплайн Эрмита по ключам `(m0_in, time, value, m1_out)`, все float32. Касательные уже умножены на длину сегмента. Код: `0x407c64..0x407d25`.

```
if ключ один или q <= t[0]:  return v[0]
q = min(q, t[last])
i = первый ключ, у которого t[i] >= q     // при равных t побеждает более ранний сегмент
s = (q - t0) / (t1 - t0)
d = v1 - v0
a = 3·d - 2·m0 - m1
b = m0 + m1 - 2·d
return v0 + s·(m0 + s·(a + s·b))           // float32, в этом порядке
```

В 20 кривых есть ключи с одинаковым временем — это намеренные скачки значения. Если отсортировать ключи или убрать дубли, анимация изменится.

## Камера

Луч камеры строится в шейдере (`0x4184b8`) по `uOrigin`, `uAngles`, `uFisheye`, `uFovBias`:

```
uv   = (2·pixel - resolution) / height
uv  *= 1 - (1 - dot(uv, uv)/4) · uFisheye
dir  = поворот xz на uv.x·uFovBias, затем yz на uv.y·uFovBias,
       затем xy (roll), yz (pitch), xz (yaw)
pR(p, a) = p·cos(a) + vec2(p.y, -p.x)·sin(a)
```

Камера и босс (`uEolBossPosition`) задаются кривыми напрямую, без физики.
